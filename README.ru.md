TrackJudge — Windows-приложение, которое загружает до пяти вариантов одного
трека, оценивает качество аудио и сохраняет лучший вариант. Для автоматизации
и разработки также доступен дополнительный режим командной строки.

## Возможности

- Принимает до пяти ссылок на YouTube и другие поддерживаемые источники.
- Загружает лучший доступный аудиопоток через `yt-dlp`.
- Сравнивает кодек, битрейт, спектральный срез, структуру высоких частот и
  корреляцию стереоканалов.
- Обнаруживает подозрительный апскейл и стационарный высокочастотный шум.
- По возможности сохраняет победителя без повторного кодирования.
- Создаёт необязательный JSON-отчёт и спектрограммы всех вариантов.
- Поддерживает русский, английский и немецкий языки интерфейса.
- Автоматически обновляет `yt-dlp` и откатывается на рабочую версию, если
  обновление оказалось неудачным.

> TrackJudge использует эвристическое сравнение и не является инструментом
> криминалистического подтверждения происхождения аудио. Наиболее точный
> результат получается при сравнении разных источников одной записи и мастера.

## Скачать

### Установщик Windows — рекомендуется

[Скачать установщик TrackJudge](https://github.com/emmzde/track-judge/releases/latest/download/TrackJudge-Setup-Windows-x64.exe)

Запустите установщик один раз. TrackJudge установится для текущего пользователя
Windows и создаст ярлыки на рабочем столе и в меню «Пуск». Python, FFmpeg,
FFprobe, `yt-dlp` и все необходимые библиотеки уже включены.

Перед сравнением онлайн-источников TrackJudge проверяет наличие свежей версии
`yt-dlp`. Обновления сохраняются в локальных данных текущего пользователя,
проверяются официальным механизмом обновления и не заменяют встроенную
резервную копию. Если новая версия не может скачать ни один источник,
TrackJudge восстанавливает предыдущую рабочую версию и повторяет попытку.

### Портативная версия

[Скачать портативный ZIP](https://github.com/emmzde/track-judge/releases/latest/download/TrackJudge-Windows-x64.zip)

Распакуйте архив и запустите `TrackJudge.exe`. Портативная версия не создаёт
ярлыки и не изменяет `PATH`. Обновляемая копия `yt-dlp` хранится в локальных
данных текущего пользователя Windows.

Неподписанная сборка может вызвать предупреждение Windows SmartScreen.
К каждому релизу приложены файлы с контрольными суммами SHA-256.

## Использование

1. Вставьте от одной до пяти ссылок на разные варианты одного трека.
2. Выберите папку для сохранения победителя.
3. При необходимости включите спектрограммы и JSON-отчёт.
4. Нажмите **«Начать сравнение»**.
5. Просмотрите результат, оценки, предупреждения и спектрограммы.

Временные отчёты и спектрограммы удаляются после закрытия приложения, если
пользователь не сохранил их копии.

## Запуск из исходного кода

```bash
git clone https://github.com/emmzde/track-judge.git
cd track-judge
python -m venv .venv
```

Активируйте окружение:

```powershell
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
```

```bash
# Linux или macOS
source .venv/bin/activate
```

Установите проект вместе с зависимостями для разработки и спектрограмм:

```bash
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

При запуске из исходного кода FFmpeg и FFprobe должны быть доступны через
`PATH`.

Запустите графическое приложение:

```bash
trackjudge-gui
```

Запустите проверки:

```bash
ruff check .
ruff format --check .
pytest
```

## Дополнительный режим командной строки

Сравнение онлайн-источников:

```bash
trackjudge "URL_1" "URL_2" "URL_3"
```

Сравнение локальных аудиофайлов:

```bash
trackjudge ./candidate-a.flac ./candidate-b.m4a
```

Сохранение спектрограммы и JSON-отчёта:

```bash
trackjudge "URL_1" "URL_2" \
  --spectrogram \
  --json-report \
  --output ./results
```

Полный список параметров доступен через `trackjudge --help`.

## Как рассчитывается оценка

Для каждого варианта TrackJudge:

1. извлекает до пяти минут из центральной части трека;
2. приводит поток анализа максимум к двум каналам и частоте 48 кГц;
3. рассчитывает медианный спектр мощности методом STFT;
4. оценивает эффективный и исходный спектральный срез;
5. измеряет модуляцию и корреляцию в контрольной полосе высоких частот;
6. применяет проверки надёжности и ранжирует все допустимые варианты.

JSON-отчёт содержит сведения о кодеке, длительности, спектральных измерениях,
оценке подлинности, предупреждениях и сохранённых файлах.

## Сборка Windows-релиза

```powershell
.\scripts\build-portable.ps1
.\scripts\build-installer.ps1
```

Сборка использует закреплённые и проверенные по контрольным суммам версии
`yt-dlp` и FFmpeg, выполняет GUI- и аудио-smoke-тесты и создаёт:

- `dist/TrackJudge-Windows-x64.zip`;
- `dist/TrackJudge-Setup-Windows-x64.exe`;
- соответствующие файлы SHA-256.

Отправка Git-тега вида `v*` запускает тот же процесс через GitHub Actions.
Кроме того, репозиторий еженедельно проверяет извлечение аудио с YouTube и
получает предложения об обновлении зависимостей через Dependabot.

## Правовые вопросы и безопасность

Загружайте только те материалы, к которым у вас есть законный доступ и право
на сохранение. Cookies браузера используются только после ответа
антибот-защиты и не сохраняются TrackJudge. Распространённые имена файлов
cookies и создаваемые медиафайлы исключены через `.gitignore`.

Сторонние компоненты и их лицензии перечислены в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Портативная сборка также
содержит уведомления, поставляемые вместе с FFmpeg.

Автоматическое обновление `yt-dlp` использует официальный nightly-канал.
Переменная `TRACKJUDGE_DISABLE_YTDLP_UPDATE=1` отключает обновления, а
`TRACKJUDGE_YTDLP_CHANNEL=stable` переключает приложение на стабильный канал.
