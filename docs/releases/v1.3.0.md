## Русский

- Студия на WebView2 и React. Крупные карточки источников, прозрачный заголовок окна Windows, чёрный фон и графитовый плеер.
- Локальный Manrope с кириллицей, векторные иконки настроек, языка и кнопок окна. Интерфейс и текст масштабируются с DPI монитора.
- Предпрослушивание каждого кандидата в WaveSurfer. Волна строится по PCM анализа. Можно перематывать, переключать кандидатов и менять громкость.
- FFmpeg декодирует до пяти минут из центра длинной записи. Спектр считается блоками, исходные локальные файлы читаются на месте. Победитель сохраняется без перекодирования, если формат позволяет.
- Рейтинг, спектрограммы и JSON доступны из окна анализа. CLI использует тот же аудиотракт.

## English

- WebView2 and React desktop studio with larger source cards, a transparent Windows title bar, a black workspace, and a graphite player.
- Bundled Manrope with Cyrillic, vector settings, language, and window icons, and per-monitor DPI awareness.
- WaveSurfer previews each candidate from the analysis PCM. Seek, switch candidates, and adjust volume from the player.
- FFmpeg decodes up to five minutes from the center of long tracks. Spectrum calculations run in blocks, local sources are read in place, and the winner is saved without re-encoding when its format allows.
- Ranking, spectrograms, and JSON are available in the analysis view. The CLI uses the same audio pipeline.
