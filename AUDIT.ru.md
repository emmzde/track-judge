# Технический аудит TrackJudge

## Архитектура

Ревью охватило исходники Python, тесты, конфигурацию зависимостей, сценарии CI, обновление загрузчика, сборку portable и установщика. Карта каталогов и команды запуска приведены в русском README.

| Участок | Исходная проблема | Изменение |
| --- | --- | --- |
| Окно | Один модуль почти на 5 000 строк содержал ручную отрисовку, две реализации экрана анализа, переводы и фоновую задачу | Представление перенесено в React. Состояние сравнения и временные ресурсы принадлежат одной сессии Python |
| Масштабирование | Переключение языка и разворачивание окна инициировали пересборку виджетов и ручное изменение метрик шрифта | Разметка пересчитывается средствами браузера. Манифест задаёт Per-Monitor V2. Manrope с кириллицей поставляется в локальных WOFF2 |
| Журнал | Число строк в списке было ограничено, отображаемый текст продолжал расти | Потокобезопасный буфер хранит последние 600 строк |
| CLI и движок | Разбор аргументов, запуск внешних процессов, вычисления, рендеринг и отчёты находились в одном файле | CLI и окно используют один сценарий сравнения. Ввод-вывод, DSP и отчёты вынесены в отдельные модули |

## Аудиотракт

| Участок | Что изменилось |
| --- | --- |
| Получение источника | Сетевые загрузки остаются последовательными. Локальные файлы читаются на месте. Копия оригинала создаётся только для сохранения победителя |
| Проба и декодирование | FFprobe и FFmpeg работают с первой аудиодорожкой. Выход PCM ограничен 300 секундами при любой длительности в метаданных. Для длинных треков берётся центр. Частота ограничена сверху 48 кГц, моно сохраняется, многоканальный звук сводится в стерео |
| Измерения | Float PCM читается через отображение файла в память. Для WAV с упакованными 24-битными отсчётами предусмотрено обычное чтение. Восьмибитный беззнаковый PCM центрируется. Анализ стереозаписей с практически полным противофазным гашением использует канал с наибольшей энергией |
| Спектр | Односторонняя спектральная плотность рассчитывается по 64 окна за проход. Сохранены периодическое окно Ханна на 4 096 отсчётов, перекрытие 50%, удаление среднего каждого окна и точная медиана по частотным строкам. Полная матрица плотности ограничена длительностью окна анализа |
| Корреляция | Полосовые фильтры обрабатывают стереоблоки с перекрытием на краях. Для итоговой корреляции накапливаются суммы, энергии и перекрёстные произведения |
| Ранжирование | Сохранены пороги, ограничение оценки коротких записей и порядок разрешения равенства по оценке, полезному срезу, достоверности ВЧ и битрейту |
| Предпрослушивание | WaveSurfer использует пики того же PCM, который прошёл анализ. Медиапоток поддерживает HTTP Range на loopback. При смене кандидата освобождается предыдущий плеер. Временные фрагменты принадлежат сессии |
| Графики и экспорт | Рендеринг Matplotlib сериализован между рабочими потоками. Сохранение аудио, PNG и JSON выполняется через подготовленный файл и эксклюзивное резервирование имени. Версии WebM Opus перепаковываются без перекодирования |
| Запись и микрофон | Рабочий сценарий использует готовые аудиофайлы и сетевые источники. Входные устройства приложению не требуются |

## Проверки

- На контрольном 60-секундном стереофайле 48 кГц при отдельном запуске процесса пиковый рабочий набор снизился с 370 до 152 МиБ. Время функции анализа составило 0,45 с до изменений и 0,33 с после. Измерение выполнено без построения PNG. Обе реализации получили 22/100 и полезный срез 16 488 Гц.
- Регрессионные тесты проверяют совпадение спектральной плотности с эталоном SciPy, музыкальные и шумовые ВЧ, противофазное стерео, неизвестную длительность, повреждённый источник, сохранность оригинала и конкурентное сохранение файлов.
- В окне WebView2 проверены смена языка, загрузка локальной кириллицы, воспроизведение, пауза, перемотка, выбор версии, открытие спектрограммы, экспорт PNG, журнал и раскладка шириной 480 CSS-пикселей.
- В окне WebView2 при плотности 1× и эмуляции 1,25×, 1,5× и 2× движок подтвердил использование локального Manrope для кириллического заголовка.
- Сетевой тракт проверен через настоящий yt-dlp на локальном HTTP-источнике. Доступ к конкретным публикациям YouTube и SoundCloud зависит от доступности сайта, ограничений сети и авторизации пользователя.
